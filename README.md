# E-Service

Web-based system designed to support the daily operations of a computer repair service and improve communication between customers and employees.

The platform provides separate functionalities for **customers** and **service employees**, covering the entire repair process — from submitting a service request to collecting the repaired device.

## Features

### For customers

* submitting repair requests
* providing device and problem details
* tracking repair status
* viewing repair history
* receiving updates about the service

### For employees

* managing service requests
* registering and updating repair information
* changing repair statuses
* managing customers and devices
* viewing the current workload and service history

## Repair workflow

```text
Customer submits request
          ↓
     Service intake
          ↓
      Diagnosis
          ↓
       Repair
          ↓
      Quality check
          ↓
    Ready for pickup
```

## Technologies

* ASP.NET
* Entity Framework
* ReactJS
* MS SQL Server

## Project

The system was developed as a practical application for managing computer repair services, with a focus on separating customer and employee workflows and providing a centralized overview of ongoing and completed repairs.
